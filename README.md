# Tidbit
<img width="2160" height="894" alt="3D_PCB1_2026-11-01" src="https://github.com/user-attachments/assets/7c4b3d25-babd-437e-9ba6-b824d32e70e1" />

Tidbit is a custom audio synthesizer and sound-control device designed around the Teensy 4.1.
The project focuses on bringing hands-on sound design into a compact hardware interface, with dedicated controls for shaping tones, adjusting parameters, and experimenting with different sound effects.

The PCB features rotary encoders for master volume, tempo, tuning, cutoff, resonance, envelope modulation, decay, accent, reverb, and drive. 
It also includes switches for waveform selection and other sound-control functions, along with push buttons for auxiliary controls and sound manipulation.

The board layout is designed to bring these controls together into an accessible physical interface. It includes dedicated areas for the
Teensy 4.1, audio connections, control switches, buttons, and supporting circuitry. The goal is to create an instrument
that makes sound experimentation more tactile and intuitive, without relying entirely on software interfaces.
<img width="2160" height="817" alt="PCB_PCB1_2026-11-01" src="https://github.com/user-attachments/assets/818f3217-7472-405f-8173-df47371d70cc" />

Tidbit is currently in the hardware design stage, with the PCB layout and 3D representation being developed to establish component placement, routing, and the overall control layout.

**Hardware:** Teensy 4.1, rotary encoders, switches, push buttons, audio connectors, and supporting circuitry.
